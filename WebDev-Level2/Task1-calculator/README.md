# Calculator Web Application

A simple and interactive calculator built using **HTML, CSS, and Vanilla JavaScript**. This project was developed as part of the Oasis Infobyte Web Development Internship (OIBSIP) – Level 2, Task 1.

## Project Overview

The Calculator Web Application allows users to perform basic arithmetic calculations through a clean and user-friendly interface.

It supports addition, subtraction, multiplication, and division, including expressions with multiple operators.

## Features

- **Basic Arithmetic:** Perform addition (+), subtraction (-), multiplication (×), and division (÷).
- **Operator Precedence:** Multiplication and division are calculated before addition and subtraction.
- **Clear (C):** Clear the entire calculation.
- **Delete (DEL):** Remove the last entered character.
- **Decimal Numbers:** Perform calculations using decimal values.
- **Error Handling:** Displays an error message when attempting to divide by zero.
- **Interactive Interface:** Responsive button layout with hover effects.

## Technologies Used

- **HTML5** – Structures the calculator interface.
- **CSS3** – Styles the calculator using CSS Grid and Flexbox.
- **JavaScript (Vanilla JS)** – Handles button interactions and performs calculations.

## How It Works

1. Users enter numbers and operators by clicking the calculator buttons.
2. JavaScript captures each button click using event listeners.
3. The entered expression is displayed in the calculator screen.
4. When the equals (=) button is clicked, the expression is evaluated.
5. Multiplication and division are processed before addition and subtraction.
6. The result is displayed on the screen.
